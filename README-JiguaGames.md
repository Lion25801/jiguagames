# JiguaGames - PS4 GoldHEN Host

Personalized web presentation based on the original GamerHack PS4 exploit-host repository.

## What was changed
- JiguaGames branding for the main host and the multi-firmware `g2all` host.
- ZENTURIA IA branding in the visible footer/credits area.
- Premium JiguaGames + ZENTURIA background.
- Root `style.css` updated for the new visual identity.
- Offline-cache manifests updated to include the new background image.
- Original host files, firmware directories, scripts and binaries were kept intact.

## GitHub Pages
Upload the **contents of this folder** to your GitHub repository (do not upload this ZIP as the site itself).

If the repository is named `USERNAME.github.io`, the site will normally be:
`https://USERNAME.github.io/`

If it is a normal repository named `JiguaGames`, the site will normally be:
`https://USERNAME.github.io/JiguaGames/`

The original repository's technical files and dependencies have been preserved. Keep the attribution/license files from the original project.
